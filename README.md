# School Weekly Review Operator Kit — Fictional Demo

**Portfolio-safe synthetic demonstration** | Python standard library | No real student/staff data

This demo demonstrates a repeatable weekly academic review operator workflow. It is an independently packaged fictional example, **not the complete school-use operator kit**. It does not import CPS SIS exports or reproduce school-only EL/IEP, gradebook, caseload, reconciliation, or authorization workflows.

## Quick start (Windows PowerShell or terminal)

Requires Python 3.9+; no packages or network connection needed.

```powershell
python run_demo.py
```

On Windows, `py run_demo.py` also works if the Python launcher is installed. This command regenerates four fictional source CSVs, recomputes six analysis CSVs, and renders the **searchable student-by-student HTML review**.

Open `reports/student_weekly_review_demo.html` in a browser. Use its priority filters and search field. A provided aggregate PDF, `reports/latest_week_demo_REFERENCE.pdf`, is a **static illustrative sample**, not refreshed by the command.

## Weekly monitoring logic

- Current F: numeric average **below 60**.
- Close to F: **60 to below 65**. Watch: **65 to below 70**.
- Compare student snapshots for new, persistent, or resolved current F status.
- Course update review: grade-posting date not within the preceding 0–6 days; **not a compliance finding**.
- Journal records contain **counts only**, not notes; zero entries do not establish that support did not happen.
- Teacher failure rate is **F student-course enrollments / all student-course enrollments** for that teacher; not a staff-performance rating.
